# Жизнь по чертежу

Реализована первая секция самостоятельного лонгрида: закрепление, проявление фотографии и заливка заголовка, вертикальное движение по фасаду, последовательные подписи, градиентный выход. Вторая секция активирована: девять оригинальных фотографий, горизонтальная лента с вертикальным управлением и три текста. Третья секция активирована: адаптированная сборка фасада из доступных PNG с обратимой прокруткой. Четвёртая секция реализована: общий план, кухня, спальня и гостиная с текстами и девятью фотографиями. Пятая секция реализована: три архивные фотографии движутся горизонтально при вертикальной прокрутке, поверх появляется заключительный текст, затем открывается существующий подвал. Одна страница, Vite, JavaScript, GSAP и ScrollTrigger. Десктопная версия ожидает согласования.

## Локальный запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Открыть адрес из терминала (обычно http://localhost:5173).

```sh
npm run build
npm run preview
```

`src/animations/` содержит отдельный модуль каждой сцены и общий файл настроек. Каждый инициализатор возвращает функцию очистки. Реализованы hero.js, history.js, construction.js, apartment.js и finale.js. Шрифты подключены локально через `@font-face`. В первой секции используется оригинал public/images/section-01/image 104.png. Параметры 17 фреймов Figma сохранены в docs/figma. Добавленные контрольные изображения находятся в public/images/references.

План и список необходимых материалов: [docs/implementation-plan.md](docs/implementation-plan.md).

## Настройка первой секции

Продолжительности и длины прокрутки: `src/animations/config.js`, поле `hero`. Общая шкала анимации управляется ScrollTrigger с scrub; после готовности фотографии и шрифтов создаётся закрепление. При изменении размеров параметры пересчитываются.

Будущие слои: `hero.facade.enabled` пока `false`, массив `layers` пуст. Контракт слоя описан в `src/animations/hero-facade.js`: координаты x/y/width/height в пикселях оригинала 1512 × 2450, at/duration в диапазоне 0–1. Видимых заглушек нет.

Статичная мелкая PNG-текстура `public/textures/grain-fine.png` лежит поверх страницы с opacity .07 и не перехватывает ввод. Мобильная композиция пока не реализована.

Проверка: production build проходит. В браузере проверены проявление до движения, последовательные подписи, обратная прокрутка до исходного состояния, градиент и снятие закрепления, пересчёт после изменения размеров. На 1512 × 850 изображение отображается как 1512 × 2450; ошибок JS и горизонтального переполнения нет. Начальный экран сопоставлен с ранее полученным изображением Figma; толщина контура 1px подобрана визуально, точный параметр обводки не был получен из Figma. Для финальной сверки нужны контрольные экспорты первой секции.

Карта шести предлагаемых изменений фасада и результат проверки пробной генерации: [docs/facade/README.md](docs/facade/README.md). Пробный слой не прошёл проверку совмещения и не подключён.
