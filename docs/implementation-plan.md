## Общие принципы будущей реализации

Инициализация в порядке DOM после готовности шрифтов и размеров изображений. Для закреплённых сцен сохранить pinSpacing; длины прокрутки вычислять от геометрии viewport и ресурсов. После загрузки ресурсов вызывать ScrollTrigger.refresh(); использовать invalidateOnRefresh. Удалять timeline, triggers и обработчики при очистке модуля. Смена состояний должна вычисляться из прогресса, включая обратную прокрутку. Не включать smooth-scroll и горизонтальную прокрутку документа.

Точные длительности согласовывать по подробным сценариям, не назначать до получения макета. Предусмотреть prefers-reduced-motion и доступность текста. Шум добавлять только после получения оригинала либо согласования текстуры, без мерцания.

Сейчас закреплений и анимаций нет. Следующий этап — только первая секция по отдельному заданию. Адаптивные композиции — после согласования десктопа. Публикация в этом подготовительном этапе не выполняется.
