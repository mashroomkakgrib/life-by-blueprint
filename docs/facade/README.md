# Карта изменений фасада

Все координаты regions.json заданы в пикселях исходника 1512 × 2450, от левого верхнего угла. Это предлагаемые области ретуши: точные маски должны сохранять архитектурные границы и исключать ветви переднего плана.

Нужны шесть независимых прозрачных PNG:

| ID | Изменение |
| --- | --- |
| window-curtains | Занавески внутри отдельного верхнего окна слева от центрального шва |
| balcony-glazing | Остекление верхнего правого балкона, с сохранением ограждения |
| window-open-sash | Приоткрытая створка отдельного окна справа от шва на следующем этаже |
| balcony-household | Небольшие бытовые предметы за ограждением среднего левого балкона |
| wall-weathering | Слабые локальные следы эксплуатации стены |
| entrance-wear | Небольшие потёртости двери подъезда |

at и duration обозначают нормализованный прогресс существующей фазы движения по фото. Изменения разнесены по высоте. Обратная прокрутка обращает ту же шкалу opacity. Длительности основной сцены, траектория фотографии, заголовок, подписи и градиент не меняются.

Карта сама по себе не является готовой графикой. Не активировать слои без проверки совмещения и фотореализма.

## Пробная генерация

Режим: встроенный ImageGen, precise-object-edit, исходная фотография как edit target, transparent_background true. Результат сохранён в generated-overlay-draft.png для проверки и НЕ подключён к сайту. Полный запрос: generation-prompt.txt.

Результат не прошёл проверку: экспорт имеет другой размер холста, содержит целые перерисованные оконные и балконные рамы вместо только локальных изменений, заметны ореолы на краях. Прямое наложение без дополнительной ретуши не гарантирует сохранения геометрии. Остекление балкона также не реализовано достоверно. Масштабировать и подключать такой слой нельзя. facade.enabled остаётся false; изменения фасада пока не завершены.

Зерно: статичная PNG-текстура 256 × 256, фиксированный seed; размер зерна 1 CSS px, непрозрачность слоя .07. body::after: position fixed, z-index 100, pointer-events none.
